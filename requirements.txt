# NpuEmbeddings -- build-time Python requirements.
#
# Build-time ONLY. Nothing here is used at runtime: the runtime is C++, and a
# release contains no Python at all (BUILD.md §1).
#
# This file is the HUMAN-READABLE list -- the packages this project asks for,
# and why. The exact bytes a build is known to work with are in
# requirements.lock.txt, which is what bootstrap.sh installs. Bump a pin here,
# then re-freeze.
#
# Targets Python 3.14 on x86_64. The MLIR-AIE / Triton-XDNA wheels are built
# per-ABI (cp314, cp313, cp312, cp311), so a different Python needs a
# different tag in requirements.amd.txt.

# The extra index torch's +cpu wheels live on. PyPI's torch is the CUDA build
# (a much larger wheel, and useless here -- there is no NVIDIA device).
